# Elementor e addons

Prefira widgets e controls nativos para manter editabilidade, responsividade e acessibilidade. Use Elementor Pro para Theme Builder, Forms, Popups, Dynamic Tags, Loop e WooCommerce quando adequado.

Happy e Jet devem ser adicionados apenas para capacidades não cobertas. Escolha uma fonte de verdade por template global, popup, menu, widget e condição.

Carregue assets sob demanda, escopе CSS, respeite `prefers-reduced-motion`, teste editor e frontend e evite HTML monolítico para conteúdo editorial.
